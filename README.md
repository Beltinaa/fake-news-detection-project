# Fake News Detection Using Machine Learning

Bachelor thesis project in Computer Engineering (Inxhinieri Informatike)
at the Polytechnic University of Tirana.

## Project Goal

This project develops machine learning models for detecting fake news
using Natural Language Processing techniques and deploys an interactive
Streamlit web application for prediction.

## Planned Pipeline

Dataset → Text preprocessing → TF-IDF → Model comparison
(Logistic Regression, Naive Bayes, SVM, Random Forest)
→ Evaluation → Streamlit demo app
